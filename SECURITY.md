# Security

## Türkçe

ScratchByPHP ile çalışırken Scratch parolalarını, `scratchsessionsid` değerlerini,
X-Token veya diğer oturum bilgilerini GitHub'a **asla commit etmeyin**.

Bir güvenlik açığı bulursanız herkese açık issue açmadan önce repo sahibine özel
kanaldan bildirin. Repo henüz bir security contact yayımlamadıysa GitHub Security
Advisories özelliğini etkinleştirmeniz önerilir.

## English

Never commit Scratch passwords, `scratchsessionsid`, X-Token values, or other
session credentials.

For security vulnerabilities, prefer a private disclosure channel such as
GitHub Security Advisories instead of a public issue.
