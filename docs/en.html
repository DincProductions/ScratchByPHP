Bridge PHP and Scratch.

ScratchByPHP provides a PHP-first layer for Scratch projects, users, studios, authenticated sessions, and Cloud Variables.

What is ScratchByPHP?

A practical bridge between ordinary PHP websites/backends and Scratch.

PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use ScratchByPHP\Scratch;

$scratch = new Scratch();
$project = $scratch->project(104);

echo $project->title();
echo $project->views();
ScratchByPHP is not an official Scratch Foundation SDK. Scratch endpoints can change.

Install with Composer

Terminal
composer require scratchbyphp/scratchbyphp
PHP
require __DIR__ . '/vendor/autoload.php';

use ScratchByPHP\Scratch;

$scratch = new Scratch();

Public API

PHP
$project = $scratch->project(104);

echo $project->title();
echo $project->author();
echo $project->views();

$user = $scratch->user('griffpatch');
$projects = $user->projects();

$studio = $scratch->studio(123456);
$curators = $studio->curators();

Authentication

PHP
$session = $scratch->login(
    'Username',
    'Password'
);

$project = $session->project(104);
$studio = $session->studio(123456);
$cloud = $session->cloud(104);
Never commit passwords, session IDs, X-Tokens, or CSRF values.

Projects

PHP
$project = $session->project(104);

$project->love();
$project->favorite();
$project->postComment('Hello from PHP');

$analysis = $project->analyze();
print_r($analysis->summary());

Player

PHP
echo $project->player(800, 600);

echo $project->run([
    'engine' => 'turbowarp',
    'width' => 900,
    'height' => 650
]);

Studios

PHP
$studio = $session->studio(123456);

$studio->addProject(104);
$studio->removeProject(104);
$studio->inviteCurator('ExampleUser');
$studio->setTitle('New title');

Cloud Variables

PHP
$cloud = $session->cloud(104);
$cloud->connect();

$value = $cloud->getRemote('score');
$result = $cloud->setVerified('score', 500);

$cloud->disconnect();

Listen for changes

PHP
$cloud->connect();

$cloud->onVariable('score', function ($value) {
    echo $value;
});

$cloud->listen();

CloudRequests

PHP
$cloud = $session->cloud(104);
$cloud->connect();

$rpc = $cloud->requests();

$rpc->on('sum', function (array $params) {
    return array_sum($params);
});

$rpc->run();

Registration Assistant

PHP
$registration = $scratch->registration();

$result = $registration->generateAvailableCredentials(
    'ScratchUser'
);

echo $registration->joinUrl();

The library does not solve or bypass CAPTCHA.

Security and responsible use

v0.8.0 hardening: credential-bearing HTTP requests are restricted to HTTPS Scratch domains, authenticated redirects are disabled, logger secrets are redacted, and session decompression is capped at 64 KiB. Plaintext account JSON remains intentional.
  • Do not log credentials or tokens.
  • Use only accounts you own or are authorized to operate.
  • Do not bypass CAPTCHA or anti-abuse controls.
  • Do not use the library for spam or artificial engagement.
