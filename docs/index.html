PHP ile Scratch arasında köprü.

ScratchByPHP; Scratch kullanıcılarını, projelerini, stüdyolarını, oturum işlemlerini ve Cloud Variables altyapısını PHP uygulamalarına bağlamayı kolaylaştırır.

5 dakikada başlaEnglish docs

ScratchByPHP nedir?

Web siteleri, yönetim panelleri ve PHP backend'leri ile Scratch arasında okunabilir bir API katmanı sağlar.

Public APIProje, kullanıcı ve stüdyo verilerini giriş yapmadan okuyun.
Authenticated APIKendi hesabınızla yorum, stüdyo ve diğer yetkili işlemleri yapın.
Scratch CloudCloud Variables ile PHP backend arasında veri alışverişi kurun.
PHP-firstShared hosting veya klasik PHP projelerine kolayca eklenebilen yapı.
ScratchByPHP resmî Scratch SDK'sı değildir. Scratch endpoint'leri değiştiğinde bazı metodların güncellenmesi gerekebilir.
PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use ScratchByPHP\Scratch;

$scratch = new Scratch();

$project = $scratch->project(104);

echo $project->title();
echo $project->views();

Composer ile kurulum

Composer, PHP'nin paket yöneticisidir. Node.js'teki npm gibi düşünebilirsiniz.

Terminal
composer require scratchbyphp/scratchbyphp

Ardından tek satır autoload yeterlidir:

PHP
<?php
require __DIR__ . '/vendor/autoload.php';

use ScratchByPHP\Scratch;

$scratch = new Scratch();
Composer kullanmak zorunda mıyım?
Hayır. ZIP ile indirirseniz repo içindeki autoload.php dosyasını kullanabilirsiniz.
PHP
require __DIR__ . '/scratchbyphp/autoload.php';

Giriş ve Session AUTH

Yazma/yönetim işlemlerinde önce Scratch hesabıyla oturum açılır.

PHP
$session = $scratch->login(
    'KullaniciAdi',
    'Sifre'
);

echo $session->username();

Session üzerinden ilgili nesneyi alın:

PHP
$project = $session->project(104);
$user    = $session->user('BirKullanici');
$studio  = $session->studio(123456);
$cloud   = $session->cloud(104);

Session ID ile giriş

PHP
$session = $scratch->loginWithSessionId(
    getenv('SCRATCH_SESSION_ID')
);
Parola, session ID, X-Token veya CSRF değerlerini GitHub'a commit etmeyin.

Cloud Variables CLOUD

Scratch projesindeki Cloud Variable'ları PHP'den okuyup yazabilirsiniz.

PHP
$cloud = $session->cloud(104);
$cloud->connect();

$value = $cloud->getRemote('score');

$result = $cloud->setVerified('score', 500);

$cloud->disconnect();

Canlı dinleme

PHP
$cloud->connect();

$cloud->onVariable('score', function ($value, $variable) {
    echo 'Yeni değer: ' . $value;
});

$cloud->listen();
Sürekli çalışan listen() işlemlerini web request'inden çok CLI/worker süreçlerinde kullanmak daha uygundur.

CloudRequests

Scratch projesinden PHP backend'e basit RPC tarzı istekler gönderin.

PHP
$cloud = $session->cloud(104);
$cloud->connect();

$rpc = $cloud->requests('request', 'response');

$rpc->on('sum', function (array $params) {
    return array_sum($params);
});

$rpc->run();

CloudDatabase

PHP
$cloud = $session->cloud(104);
$cloud->connect();

$db = $cloud->database('db');

$db->set('level', 12);
echo $db->get('level');
$db->delete('level');

$cloud->disconnect();
CloudDatabase küçük durum verileri içindir; MySQL/SQLite yerine kullanılacak genel amaçlı bir veritabanı değildir.

Registration Assistant

Rastgele credential üretimi ve username kontrolü sağlar. CAPTCHA'yı çözmez veya atlamaz.

PHP
$registration = $scratch->registration();

$result = $registration->generateAvailableCredentials(
    'ScratchUser'
);

echo $registration->joinUrl();

JSON credential profili

PHP
$json = $registration->credentialsJson(
    'ScratchUser_ABC123',
    'StrongPassword123!',
    'mail@example.com'
);

$data = $registration->parseCredentialsJson($json);
Credential JSON düz metin parola içerebilir. Dosyayı parola gibi koruyun.

Hata yönetimi

PHP
use ScratchByPHP\Exceptions\LoginException;
use ScratchByPHP\Exceptions\ApiException;

try {
    $session = $scratch->login($username, $password);
} catch (LoginException $e) {
    echo 'Giriş başarısız: ' . $e->getMessage();
} catch (ApiException $e) {
    echo 'API hatası: ' . $e->getMessage();
}

Güvenlik ve sorumlu kullanım

v0.5.1 hardening: Auth istekleri yalnız HTTPS Scratch domainlerine gider; auth redirectleri kapalıdır; logger secret değerleri maskeler; session decoder 64 KiB ile sınırlıdır. Plaintext hesap JSON formatı bilinçli olarak korunur.
  • Credential/token bilgilerini loglamayın.
  • Kendi hesabınız veya yetkili olduğunuz hesapları kullanın.
  • CAPTCHA/anti-abuse kontrollerini atlatmayın.
  • Spam veya yapay etkileşim üretmek için kullanmayın.
  • Scratch topluluk kurallarına uyun.

Teşekkür ve kaynaklar

ScratchByPHP'nin API tasarımı ve özellik kapsamı geliştirilirken TimMcCool'un scratchattach projesi önemli bir referans ve ilham kaynağı olmuştur. scratchattach MIT lisanslı bir Python Scratch API/Cloud araç setidir.

ScratchByPHP bağımsız bir PHP uygulamasıdır; scratchattach'ın resmî PHP portu değildir.

ScratchByPHP v0.5.1 · MIT · Scratch Foundation ile bağlantılı değildir.
